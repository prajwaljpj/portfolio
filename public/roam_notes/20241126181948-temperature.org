#+title: Temperature
#+filetags: :python-example:definition:LLM:

Temperature in the context of language models (LLMs) is a hyperparameter that controls the randomness of the model's predictions. When generating text, a model can produce outputs with varying degrees of randomness based on the value of temperature.

*** Concept

- *Low Temperature (e.g., 0.1)*: The model will favor more probable tokens, leading to more deterministic and focused outputs. It is likely to repeat phrases or generate more common responses.
- *High Temperature (e.g., 1.0 or above)*: The model produces more diverse and creative responses, as it allows for less probable tokens to be selected, increasing randomness.

*** Mathematical Explanation

The temperature is applied to the softmax function, which converts the logits (raw model outputs) into probabilities. The formula for the softmax function with temperature \( T \) is:

\[
P_i = \frac{e^{(logit_i / T)}}{\sum_{j} e^{(logit_j / T)}}
\]

Where:
- \( P_i \) is the probability of token \( i \).
- \( logit_i \) is the raw model output for token \( i \).
- \( T \) is the temperature.

*Effect of Temperature:*
- When \( T = 1 \), the softmax behaves normally.
- As \( T \) approaches 0, the model's output concentrates on the most likely token, making the output more deterministic.
- As \( T \) increases, the distribution flattens, leading to greater diversity in output.

*** Python Example

Here is a simple example of how to implement temperature sampling in Python:

#+begin_src python
import numpy as np

def softmax(logits, temperature=1.0):
    # Apply temperature
    logits = logits / temperature
    exp_logits = np.exp(logits)
    return exp_logits / np.sum(exp_logits)

def temperature_sample(logits, temperature=1.0):
    # Calculate probabilities using softmax with temperature
    probabilities = softmax(logits, temperature)
    # Sample from our probability distribution
    return np.random.choice(len(probabilities), p=probabilities)

# Example logits from a hypothetical model
logits = np.array([2.0, 1.0, 0.1])

# Sample a token with different temperatures
for T in [0.1, 0.5, 1.0, 1.5]:
    sampled_index = temperature_sample(logits, temperature=T)
    print(f"Sampled index at temperature {T}: {sampled_index}")
#+end_src

*** Summary

Adjusting the temperature allows you to control the creativity and diversity of responses from an LLM. *Lower temperatures produce safer outputs, while higher temperatures can lead to novel and unexpected results*.
