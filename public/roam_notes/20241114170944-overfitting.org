#+title: Overfitting

Overfitting occurs in machine learning when a model learns the training data too well, capturing noise and details to the extent that it negatively impacts its performance on new, unseen data.

*** Example using Python and Scikit-learn:

Here's a simple example to demonstrate overfitting using a polynomial regression model.

#+begin_src python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

# Generate synthetic data
np.random.seed(0)
X = 2 - 3 * np.random.rand(100, 1)
y = X ** 2 + np.random.randn(100, 1)

# Split data into training and testing sets
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)

# Fit a linear model (underfitting)
linear_model = LinearRegression()
linear_model.fit(X_train, y_train)

# Make predictions
y_pred_linear = linear_model.predict(X_test)

# Fit a polynomial model (overfitting)
poly_features = PolynomialFeatures(degree=15)
X_poly = poly_features.fit_transform(X_train)
poly_model = LinearRegression()
poly_model.fit(X_poly, y_train)

# Predict with polynomial model
y_pred_poly = poly_model.predict(poly_features.transform(X_test))

# Calculate and display the mean squared error
mse_linear = mean_squared_error(y_test, y_pred_linear)
mse_poly = mean_squared_error(y_test, y_pred_poly)

# Plot the results
plt.scatter(X_test, y_test, color='black', label='Data')
plt.plot(X_test, y_pred_linear, color='blue', label='Linear model')
plt.scatter(X_test, y_pred_poly, color='red', label='Polynomial model', marker='x')
plt.title(f'MSE Linear: {mse_linear:.2f}, MSE Polynomial: {mse_poly:.2f}')
plt.legend()
plt.show()
#+end_src

*** Explanation:
1. *Data Generation*: We create a simple quadratic relationship and add noise.
2. *Model Training*: We train both a linear and a high-degree polynomial model.
3. *Performance Evaluation*: The Mean Squared Error (MSE) is calculated for both models.
4. *Visualization*: The plot shows how the polynomial model captures the training data closely but fails to generalize well to the test data, indicating overfitting.

In general, an overfitted model will display lower error on the training dataset but higher error on the validation/test dataset, which illustrates its inability to generalize to unseen data.
