#+title: Model Loss

Model loss functions, also known as cost functions or objective functions, quantify how well a model's predictions align with the actual data. They provide a measure of the model's performance, guiding the optimization process during training. The goal is to minimize the loss function to improve the model's accuracy.

*** Types of Loss Functions

1. *Regression Loss Functions:*
   - *Mean Squared Error (MSE):*
     \[
     \text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
     \]
     *Example:* If the true values are [3, -0.5, 2] and the predicted values are [2.5, 0.0, 2], MSE would be calculated as:
     \[
     \text{MSE} = \frac{1}{3} \left( (3 - 2.5)^2 + (-0.5 - 0)^2 + (2 - 2)^2 \right) = \frac{1}{3} \left( 0.25 + 0.25 + 0 \right) = \frac{0.5}{3} \approx 0.167
     \]

   - *Mean Absolute Error (MAE):*
     \[
     \text{MAE} = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|
     \]
     *Example:* Using the same true and predicted values:
     \[
     \text{MAE} = \frac{1}{3} \left( |3 - 2.5| + |-0.5 - 0| + |2 - 2| \right) = \frac{1}{3} \left( 0.5 + 0.5 + 0 \right) = \frac{1}{3} \approx 0.333
     \]

2. *Classification Loss Functions:*
   - *Binary Cross-Entropy (Log Loss):*
     \[
     \text{Binary Cross-Entropy} = -\frac{1}{n} \sum_{i=1}^{n} [y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i)]
     \]
     *Example:* For true labels [1, 0] and predicted probabilities [0.9, 0.1]:
     \[
     \text{BCE} = -\frac{1}{2} \left( 1 \cdot \log(0.9) + 0 \cdot \log(0.1) \right) \approx -\frac{1}{2} \cdot (-0.105) \approx 0.0525
     \]

   - *Categorical Cross-Entropy:*
     Used for multi-class classification tasks.
     \[
     \text{CCE} = -\sum_{i=1}^{C} y_i \log(\hat{y}_i)
     \]
     *Example:* If we have three classes, true labels [0, 1, 0] and predicted [0.1, 0.8, 0.1]:
     \[
     \text{CCE} = -[0 \cdot \log(0.1) + 1 \cdot \log(0.8) + 0 \cdot \log(0.1)] \approx -\log(0.8) \approx 0.223
     \]

*** Conclusion
Loss functions are crucial for model training. They capture the difference between predicted and actual values, with various forms suited for different types of problems (regression or classification). Minimizing the loss is essential for improving the model's performance.
