#+title: Types of Losses


In machine learning, loss functions measure how well a model's predictions align with the actual outcomes. Here are some common types of losses, along with examples in Python:

*** 1. *Mean Squared Error (MSE)*
Used for regression tasks, it calculates the average of the squared differences between predicted and actual values.

#+begin_src python
import numpy as np

def mean_squared_error(y_true, y_pred):
    return np.mean((y_true - y_pred) ** 2)

# Example usage
y_true = np.array([2.0, 3.0, 5.0])
y_pred = np.array([2.5, 2.0, 5.5])
print("MSE:", mean_squared_error(y_true, y_pred))
#+end_src

*** 2. *Mean Absolute Error (MAE)*
Also used for regression, it measures the average of the absolute differences between predictions and actual values.

#+begin_src python
def mean_absolute_error(y_true, y_pred):
    return np.mean(np.abs(y_true - y_pred))

# Example usage
print("MAE:", mean_absolute_error(y_true, y_pred))
#+end_src

*** 3. *Binary Cross-Entropy Loss*
Used for binary classification, it measures the performance of a model whose output is a probability value between 0 and 1.

#+begin_src python
from sklearn.metrics import log_loss

# Example usage
y_true = np.array([1, 0, 1])
y_pred = np.array([0.9, 0.1, 0.8])
print("Binary Cross-Entropy Loss:", log_loss(y_true, y_pred))
#+end_src

*** 4. *Categorical Cross-Entropy Loss*
Used for multi-class classification problems, it measures the difference between two probability distributions - true labels and predicted labels.

#+begin_src python
from keras.losses import categorical_crossentropy

# Example usage
y_true = np.array([[0, 1], [1, 0], [0, 1]])  # One-hot encoding
y_pred = np.array([[0.1, 0.9], [0.8, 0.2], [0.2, 0.8]])
print("Categorical Cross-Entropy Loss:", categorical_crossentropy(y_true, y_pred).numpy())
#+end_src

*** 5. *Hinge Loss*
Used for "maximum-margin" classification, primarily with Support Vector Machines (SVM).

#+begin_src python
def hinge_loss(y_true, y_pred):
    return np.mean(np.maximum(0, 1 - y_true * y_pred))

# Example usage
y_true = np.array([1, -1, 1])
y_pred = np.array([0.8, -0.5, 1.0])
print("Hinge Loss:", hinge_loss(y_true, y_pred))
#+end_src

Each of these loss functions is critical in guiding model optimization during training. Choosing the right loss function is essential for the performance of machine learning models.
