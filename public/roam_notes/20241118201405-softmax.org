#+title: Softmax
#+filetags: :definition:python-example:

Softmax is a mathematical function commonly used in machine learning, particularly for multi-class classification problems. It converts a vector of raw scores (logits) into probabilities that sum up to 1, making it suitable for interpreting outputs as probabilities across different classes.

*** Mathematical Definition

Given a vector \( z = [z_1, z_2, ..., z_n] \), the softmax function is defined as:

\[
\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{n} e^{z_j}} \quad \text{for } i = 1, ..., n
\]

Where:
- \( e \) is the base of the natural logarithm.
- \( z_i \) is the i-th element of the input vector \( z \).
- The denominator sums the exponentials of all elements in the vector, ensuring that the outputs are normalized to sum to 1.

*** Example in Python

Here's how to implement the softmax function in Python:

#+begin_src python
import numpy as np

def softmax(z):
    exp_z = np.exp(z - np.max(z))  # subtract max for numerical stability
    return exp_z / exp_z.sum(axis=0)

# Example usage
logits = np.array([2.0, 1.0, 0.1])
probabilities = softmax(logits)
print(probabilities)
#+end_src

For the input =[2.0, 1.0, 0.1]=, the output probabilities will be approximately:

#+end_src

These values represent the probabilities of each class, summing up to 1.
