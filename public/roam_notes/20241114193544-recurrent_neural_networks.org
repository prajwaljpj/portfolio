#+title: Recurrent Neural Networks

Recurrent Neural Networks (RNNs) are specialized for processing sequences of data, leveraging their ability to maintain a hidden state, which acts as memory to store information about previous inputs. This is achieved through loops in the network, allowing information to persist across time steps. Here are some key points about RNNs:

1. *Architecture*: An RNN consists of input, hidden, and output layers. At each time step, the network receives an input and updates its hidden state, which is then used to predict the output for that time step.

2. *Training*: RNNs are typically trained using backpropagation through time (BPTT), a variation of standard backpropagation that accounts for the sequential nature of the data. It feeds the error gradient backward through the time steps to update the weights.

3. *Limitations*: Traditional RNNs can struggle with long-term dependencies due to issues like vanishing and exploding gradients. To address this, more advanced architectures have been developed, such as Long Short-Term Memory (LSTM) networks and Gated Recurrent Units (GRUs), which include mechanisms to better retain information over extended periods.

4. *Applications*: RNNs are widely used in various applications, including:
   - Natural Language Processing (NLP) for tasks like language translation and sentiment analysis.
   - Time series prediction in finance or weather forecasting.
   - Speech recognition and audio processing.

5. *Variants*: There are several RNN variants:
   - *Bidirectional RNNs*: Process input sequences in both forward and backward directions to capture context from both past and future.
   - *Attention Mechanisms*: Allow the model to focus selectively on different parts of the input sequence, improving performance in tasks like machine translation.

Overall, RNNs and their advanced iterations are crucial for handling sequential data, making them fundamental to many modern machine learning applications.

*** Example of an RNN in Python using TensorFlow/Keras

#+begin_src python
import numpy as np
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import SimpleRNN, Dense

# Generate dummy sequential data
# Assume we want to predict the next number in a sequence
data = np.array([[i, i+1, i+2] for i in range(100)])  # Shapes (100, 3)
X = data[:, :-1]  # Input shape (100, 2)
y = data[:, -1]   # Output shape (100,)

# Reshape X for RNN input
X = X.reshape((100, 2, 1))  # (samples, time steps, features)

# Create RNN model
model = Sequential()
model.add(SimpleRNN(10, activation='tanh', input_shape=(2, 1)))  # 10 hidden units
model.add(Dense(1))  # Output layer

# Compile model
model.compile(optimizer='adam', loss='mean_squared_error')

# Train model
model.fit(X, y, epochs=200, verbose=0)
