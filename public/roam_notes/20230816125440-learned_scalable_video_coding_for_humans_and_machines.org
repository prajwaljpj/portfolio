#+title: Learned Scalable Video Coding for Humans and Machines

* Abstract
- Video coding developed to support video streaming, videoconferencing, digital TV, etc
- Used for human viewing
- Advances of DNN have been used for video analysis such as vehicle detection, tracking, etc
- A new video coding facilitating representation, and compression is required for both human viewing and machine use
- In this paper, they propose a end to end learnable video codec system based on conditional coding that supports machine vision task in its base layer and additionally an enhancement layer that supports input reconstruction for human viewing

* Motivation
- Analysis of conditional coding vs residual coding from a rate distortion point of view.
- Conditional coding has been argued to offer better compression in comparison to residual coding but, the arguments are done only on lossless compression.
- $\mathbb{H}(\mathbb{X}|\mathbb{Y}) \le \mathbb{H}(\mathbb{X} - \mathbb{Y})$ where $\mathbb{H}(\cdot)$ is the entropy and $\mathbb{H}(\cdot | \cdot)$ is the conditional entropy for input RV $\mathbb{X}$ and output predictor $\mathbb{Y}$. This shows that conditional coding is better than residual coding since entropy is the limit for lossless compression. However, for practical lossy codecs, rate-distortion theory is employed for analysis.
